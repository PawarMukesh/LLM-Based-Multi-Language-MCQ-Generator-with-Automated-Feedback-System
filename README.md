# 🧠 LLM-Based-Multi-Language-MCQ-Generator-with-Automated-Feedback-System

This project utilizes a Large Language Model (LLM) to generate multiple-choice questions (MCQs) across various programming languages such as Python, Java, and C++. The tool dynamically creates questions based on user-provided input or predefined topics and provides immediate feedback on selected answers.

## 🔧 Key Features
- Multi-language Support: Generate MCQs for Python, Java, C++, and more.
- LLM Integration: Powered by advanced LLMs like Gemini Pro to ensure contextual accuracy and question quality.
- Automated Feedback: Provides explanations for correct and incorrect answers.
- User Interface: Built with Streamlit and Gradio for an interactive and responsive experience.
- Flexible Input: Accepts text-based prompts. 
- Customizable Difficulty Levels: Allows users to select question complexity.

## 📁 Technologies Used
1. Gemini Pro (Generative AI)
2. Python
3. Streamlit & Gradio (UI Frameworks)
4. OpenAI / Google Generative AI APIs

## 📌 Use Cases
1. Interview Preparation
2. E-learning Platforms
3. Automated Assessment Tools
4. Programming Quizzes
